      创建一个防抖函数，在最后一次调用后等待 delay 毫秒再执行 fn。

      Type Parameters

      • T extends (...args: any[]) => any

      Parameters

      • fn: T

        需要防抖执行的函数

      • delay: number

        防抖延迟时间（毫秒）

      • Optionaloptions: { leading?: boolean }

        可选配置

        • Optionalleading?: boolean

          是否在延迟开始前立即执行一次（默认 false）

      Returns {
          cancel: () => void;
          flush: () => ReturnType<T> | undefined;
          (...args: Parameters<T>): ReturnType<T> | undefined;
      }

      防抖后的函数，附带 cancel() 和 flush() 方法

      Example

      const debounced = debounce((msg: string) => console.log(msg), 200)
      debounced('hello') // 200ms 后输出 'hello'
      debounced.cancel() // 取消本次调度

      const leading = debounce(() => save(), 300, { leading: true })
      leading() // 立即执行 save
