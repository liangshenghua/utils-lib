    • mapTreeData(
          treeData?: Record<string, any>[],
          fields?: string[],
          childrenKey?: string,
      ): Record<string, any>[]

      递归提取树结构，只保留指定字段。

      Parameters

      • treeData: Record<string, any>[] = []

        树形数据源（默认 []）

      • fields: string[] = ...

        需要保留的字段列表（默认 ['id', 'name']）

      • childrenKey: string = 'children'

        下级节点字段名（默认 'children'）

      Returns Record<string, any>[]

      提取后的树形结构数据

      Example

      mapTreeData([{ id: 1, name: 'a', code: 'x', extra: true }], ['id', 'name'])
      // => [{ id: 1, name: 'a' }]

      mapTreeData([{ id: 1, children: [{ id: 2, name: 'b' }] }], ['id'], 'children')
      // => [{ id: 1, children: [{ id: 2 }] }]
